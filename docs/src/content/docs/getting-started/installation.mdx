## Purchase a License

Filament Satis is distributed through [Anystack](https://checkout.anystack.sh/filament-satis). Visit the product page, purchase a license, and note your **email** and **license key**.

## Add the Private Registry

Add the Anystack Composer registry to your project's `composer.json`:

```json
{
  "repositories": [
    {
      "type": "composer",
      "url": "https://filament-satis.composer.sh"
    }
  ]
}
```

## Require the Package

```bash
composer require jeffersongoncalves/filament-satis
```

You will be prompted for credentials:

```
Loading composer repositories with package information
Authentication required (filament-satis.composer.sh):
Username: [licensee-email]
Password: [license-key]
```

- **Username**: The email address associated with your license
- **Password**: Your license key

:::tip
If your license requires a fingerprint, append it to the license key separated by a colon:
`license-key:fingerprint`

If the license is not assigned to a licensee, use `unlock` as the username.
:::

To store credentials permanently so you are not prompted every time:

```bash
composer config http-basic.filament-satis.composer.sh "[licensee-email]" "[license-key]"
```

:::caution
Never commit `auth.json` to version control. Add it to your `.gitignore`.
:::

## Publish Migrations

```bash
php artisan vendor:publish --tag="filament-satis-migrations"
php artisan migrate
```

This creates the following tables (all prefixed with `satis_` by default):

| Table | Purpose |
|-------|---------|
| `satis_packages` | Package sources |
| `satis_tokens` | Authentication tokens |
| `satis_package_releases` | Version/release data |
| `satis_dependencies` | Dependency records |
| `satis_package_downloads` | Download statistics |
| `satis_packagists` | Packagist metadata |
| `satis_package_token` | Package-token pivot |
| `satis_dependency_package_release` | Dependency-release pivot |

## Publish Config (Optional)

```bash
php artisan vendor:publish --tag="filament-satis-config"
```

This publishes `config/filament-satis.php` where you can customize tenancy, storage, queue, scheduling, and more.

## Satis Binary

Satis (`composer/satis`) is included as a dependency and installed automatically. By default, the plugin uses `vendor/bin/satis`.

To use a different binary, set a custom path in the config:

```php
'satis_binary' => '/usr/local/bin/satis',
```
