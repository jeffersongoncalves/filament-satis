Follow these steps to go from installation to a working private Composer repository.

<Steps>

1. **Register the plugin in your Filament panel**

   ```php
   // app/Providers/Filament/AdminPanelProvider.php
   use JeffersonGoncalves\FilamentSatis\FilamentSatisPlugin;

   public function panel(Panel $panel): Panel
   {
       return $panel
           ->plugins([
               FilamentSatisPlugin::make(),
           ]);
   }
   ```

2. **Add a package**

   Go to **Satis > Packages** in your admin panel and create a new package:

   - **Name**: e.g. `vendor/my-package`
   - **Type**: `Composer` or `GitHub`
   - **URL**: The repository URL
   - **Credentials**: Username and password/token if the repo is private

3. **Create a token**

   Go to **Satis > Tokens** and create a new token:

   - **Name**: A label for this client (e.g. `production-server`)
   - **Email**: Contact email
   - Assign the packages this token should access

   Copy the generated token value — you'll need it in the next step.

4. **Build the repository**

   Run the build command:

   ```bash
   php artisan satis:build
   ```

   This generates `packages.json` and archives for each token's package set.

5. **Configure the client**

   On the machine that needs to pull packages, add your Satis repository to `composer.json`:

   ```json
   {
     "repositories": [
       {
         "type": "composer",
         "url": "https://your-app.com/satis"
       }
     ]
   }
   ```

   And set up authentication in `auth.json`:

   ```json
   {
     "http-basic": {
       "your-app.com": {
         "username": "token",
         "password": "your-generated-token"
       }
     }
   }
   ```

   Now you can require your private packages:

   ```bash
   composer require vendor/my-package
   ```

</Steps>
