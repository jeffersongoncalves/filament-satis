Filament Satis exposes a webhook endpoint for GitHub to trigger automatic repository rebuilds.

## GitHub Webhook

```http
POST /{api_prefix}/webhooks/github/{reference}
```

Receives GitHub push events and triggers a rebuild for the associated package.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `reference` | string | The unique reference code assigned to the package |

**Headers:**

| Header | Description |
|--------|-------------|
| `X-Hub-Signature-256` | GitHub's HMAC-SHA256 signature of the payload |
| `X-GitHub-Event` | The event type (e.g. `push`) |
| `Content-Type` | `application/json` |

**Request Body:** Standard [GitHub push event payload](https://docs.github.com/en/webhooks/webhook-events-and-payloads#push).

### Responses

| Status | Description |
|--------|-------------|
| `200 OK` | Webhook processed, rebuild dispatched |
| `401 Unauthorized` | Invalid or missing webhook signature |
| `404 Not Found` | No package found with the given reference |

### Signature Verification

The controller verifies the webhook payload against the package's stored `webhook_secret` using HMAC-SHA256:

```
X-Hub-Signature-256: sha256={signature}
```

GitHub computes this signature using the secret you configured when creating the webhook. The controller recomputes it and compares. If they don't match, the request is rejected with `401`.

## Setting Up the Webhook

1. Find the package's **reference** and **webhook secret** in the admin panel under the package's Integration section

2. In your GitHub repository, navigate to **Settings > Webhooks > Add webhook**

3. Configure:

   | Field | Value |
   |-------|-------|
   | Payload URL | `https://your-app.com/api/satis/webhooks/github/{reference}` |
   | Content type | `application/json` |
   | Secret | The package's webhook secret |
   | Events | **Just the push event** |

4. Save and verify the initial ping succeeds

## Flow Diagram

```
GitHub Repository
  │
  ├─ Push event
  │
  ▼
POST /api/satis/webhooks/github/{reference}
  │
  ├─ Verify X-Hub-Signature-256
  ├─ Look up package by reference
  ├─ Dispatch SyncTenantPackages job
  │
  ▼
Satis rebuild completes
  │
  ▼
Updated packages.json available
```
