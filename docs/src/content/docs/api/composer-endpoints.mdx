title: Composer Endpoints
description: API reference for Composer-facing routes.
---

These endpoints implement the [Composer Repository API](https://getcomposer.org/doc/05-repositories.md#composer) that Composer clients use to discover and download packages.

All Composer endpoints require authentication via the `EnsureUserHasLicense` middleware using HTTP Basic Auth or Bearer tokens.

## Packages Index

```http
GET /{composer_prefix}/packages.json
```

Returns the root `packages.json` with links to provider includes.

**Response:**

```json
{
  "packages": {},
  "includes": {
    "include/all${hash}.json": {
      "sha1": "abc123..."
    }
  }
}
```

## Package Includes

```http
GET /{composer_prefix}/include/{include}.json
```

Returns package metadata for a specific include file referenced in `packages.json`.

**Parameters:**

| Parameter | Description |
|-----------|-------------|
| `include` | The include filename (with hash) |

## Packages V2

```http
GET /{composer_prefix}/p2/{vendor}/{package}.json
```

Composer v2 metadata endpoint for a specific package.

**Parameters:**

| Parameter | Description |
|-----------|-------------|
| `vendor` | Package vendor name |
| `package` | Package name |

**Response:**

```json
{
  "packages": {
    "vendor/package": {
      "1.0.0": {
        "name": "vendor/package",
        "version": "1.0.0",
        "dist": {
          "url": "https://your-app.com/satis/archives/vendor/package/package-1.0.0.zip",
          "type": "zip"
        }
      }
    }
  }
}
```

## Archives

```http
GET /{composer_prefix}/archives/{vendor}/{package}/{file}
```

Serves package distribution archives (zip files).

**Parameters:**

| Parameter | Description |
|-----------|-------------|
| `vendor` | Package vendor name |
| `package` | Package name |
| `file` | Archive filename (e.g. `package-1.0.0.zip`) |

**Response:** Binary file stream with appropriate content headers.

## Download Tracking

```http
POST /{api_prefix}/composer/downloads
```

Records a package download. Called automatically by Composer after downloading a package.

**Request Body:**

```json
{
  "downloads": [
    {
      "name": "vendor/package",
      "version": "1.0.0"
    }
  ]
}
```

**Response:** `200 OK`

## Authentication

All endpoints authenticate using the `satis-token` guard:

- **HTTP Basic Auth**: Username is ignored, password is the token value
- **Bearer Token**: `Authorization: Bearer {token}`

Failed authentication returns `401 Unauthorized`.

## Default Prefixes

| Config Key | Default | Used By |
|------------|---------|---------|
| `composer_prefix` | `satis` | Package/include/archive routes |
| `api_prefix` | `api/satis` | Download tracking, webhooks |
