## Quick Overview

Filament Satis turns your Laravel application into a private Composer repository host. It wraps [Satis](https://github.com/composer/satis) — Composer's static repository generator — into a full admin interface built on [Filament 3](https://filamentphp.com).

With Filament Satis you can:

- Register private packages from Composer or GitHub sources
- Generate per-token `packages.json` endpoints for scoped access
- Validate credentials before building
- Track downloads and dependencies
- Run builds via Artisan commands, queued jobs, or scheduled tasks
