---
title: Multi-Tenancy
description: Isolating packages and tokens per tenant.
---

Filament Satis supports multi-tenancy, allowing you to isolate packages, tokens, and all related data per tenant.

## Enabling Multi-Tenancy

Update `config/filament-satis.php`:

```php
'tenancy' => [
    'enabled' => true,
    'model' => \App\Models\Team::class,
    'foreign_key' => 'team_id',
    'ownership_relationship' => 'team',
],
```

| Key | Description |
|-----|-------------|
| `enabled` | Toggle tenancy on/off |
| `model` | Your tenant model class |
| `foreign_key` | The column name on Satis tables that references the tenant |
| `ownership_relationship` | The Eloquent relationship name on Satis models |

## How It Works

When tenancy is enabled, the `HasTenancy` trait applies a global scope to all Satis models. This scope automatically:

- Filters all queries by the current tenant's ID
- Sets the tenant foreign key when creating new records

All models that use the `HasTenancy` trait are affected:
- `Package`
- `Token`
- `PackageRelease`
- `PackageDownload`
- `Dependency`

## Build Isolation

Builds are also tenant-isolated. The storage structure becomes:

```
storage/satis/{tenant_id}/{token_id}/
├── satis.json
├── packages.json
├── include/
└── archives/
```

Each tenant gets its own set of Satis builds, and each token within a tenant gets its own scoped repository.

## Per-Tenant Builds

You can run builds for a specific tenant:

```bash
php artisan satis:build --tenant=1
php artisan satis:validate --tenant=1
```

Without the `--tenant` flag, builds run for all tenants.

## Migrations

When tenancy is enabled, ensure the migration stubs include the tenant foreign key column. The published migrations already support this — the column is added based on your `foreign_key` config value.

## Filament Panel Integration

If you're using Filament's built-in multi-tenancy, the plugin respects the current tenant set by Filament's tenant middleware. No additional configuration is needed beyond enabling tenancy in the plugin config.
