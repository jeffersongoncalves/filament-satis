Packages are the core resource in Filament Satis. Each package represents a source repository that Satis pulls from when building your private Composer repository.

## Package Types

Filament Satis supports two package types:

### Composer

Standard Composer repository sources. These are accessed via HTTP using basic authentication.

- **URL**: The Composer repository URL (e.g. `https://packages.example.com`)
- **Username / Password**: Credentials for HTTP basic auth

### GitHub

GitHub repositories accessed via Git protocol.

- **URL**: The repository clone URL (e.g. `https://github.com/vendor/package.git`)
- **Username / Password**: A GitHub username and personal access token

## Creating a Package

Navigate to **Satis > Packages** in your Filament panel and click **Create**.

Fill in the form sections:

| Section | Fields |
|---------|--------|
| **General** | Name, Type, URL |
| **Credentials** | Username, Password |
| **Integration** | Webhook secret (auto-generated), Reference (auto-generated) |

The webhook secret and reference code are generated automatically when the package is created.

## Credential Validation

Before building, you can validate that Satis can access a package's source. The plugin checks:

- **Composer packages**: HTTP authentication against the repository URL
- **GitHub packages**: Git access using the provided token

Validation status is tracked per package:
- `is_credentials_validated` — Whether credentials have been verified
- `credentials_validated_at` — When validation last succeeded

Run validation manually:

```bash
php artisan satis:validate
```

Or rely on the scheduled validation (configurable in `config/filament-satis.php`).

## Viewing Releases

Each package has a **Releases** tab showing all discovered versions with:

- Version number
- Release type
- Timestamp
- Description
- Homepage URL

Releases are populated automatically during Satis builds.

## Viewing Downloads

The **Downloads** tab shows per-version download counts, sorted by most downloaded.
